# Position recommendations and lineup gain

Waiver list now contains separate QB, K, DEF, RB, WR and TE sections. Each lists up to three eligible imported players and a rationale. Research supplies up to two candidates per position to Qwen, requesting one selection per position and an optional displayed 0–100 subjective waiver priority rating. The rating is not fantasy points, calibrated confidence or a win probability. The Qwen score, Yahoo point projection and independent statistical point forecast appear in separate columns. Missing scores display Not scored rather than fabricated values.

Previous Qwen suggestions remain dated and marked Not updated while current work is pending, failed or stale. Current availability and kickoff rules determine eligibility; the separate previous briefing also warns when a player has left the pool or locked. Ratings are experimental and not comparable to Yahoo points. All sections still provide a statistical shortlist when Qwen is unavailable.

The overview Potential lineup gain metric opens Recommendations. The existing optimizer refreshes with the dashboard; the details show each proposed player's current slot, target slot, replaced player and both projections. All required moves should be reviewed as a set because slot reassignment can depend on other changes. Gain applies to eligible unlocked roster slots using the active statistical/Yahoo point forecast; it is not a Qwen rating or guaranteed outcome. No lineup transaction is submitted automatically.

Verification: 31 tests, including six-position score validation and out-of-range rejection, plus production build. Browser verified six position sections, separate columns and an available shortlist. See Operations for the live Qwen connectivity limitation found during validation.
